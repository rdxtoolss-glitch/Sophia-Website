Application Purpose & Functionality

What is Sophia AI and What Does It Do?

Sophia AI is an advanced Windows desktop voice assistant created by Muhammad Junaid at Mobo Devs Studio (hosted at mobodevs.net). Built with real-time conversational voice intelligence, Sophia acts as an autonomous copilot for your PC, executing multi-step workflows, system commands, and document authoring through fluid speech.

Real-Time Voice Dialogue

Natural speech with sub-second response times. Sophia listens, comprehends context, and converses fluidly with instant barge-in interruption capability.

Autonomous Desktop Action

Execute WhatsApp voice calls and messages, write and edit code in VS Code, type documents in Word, manage display brightness, and control applications hands-free.

Local-First DPAPI Security

User preferences, custom languages, and conversational memories are encrypted with Windows DPAPI on your local SSD. Zero cloud leaks, zero ads.

Google OAuth 2.0 & Workspace Data Usage Disclosure

Sophia provides an optional Sign in with Google integration in desktop settings. When connected, Sophia enables voice-activated Google Workspace integration (Google Calendar event management, Google Tasks completion, and Gmail draft composition) alongside profile identification.

  • •
    Purpose of Google Sign-In & Workspace Access: Google OAuth 2.0 authenticates the user, securely stores refresh tokens in the local encrypted directory (%APPDATA%\Sophia\data\google_tokens.json), and allows the user to say voice commands such as "What's on my Google Calendar today?", "Add a reminder to Google Tasks", or "Draft an email in Gmail".
  • •
    Strict User-Granted Scopes: Scopes requested are strictly limited to user-approved actions (OpenID profile for user greeting, Google Calendar for event scheduling, Google Tasks, and Gmail drafting/sending).
  • •
    Local Storage & Zero Selling: All OAuth tokens and retrieved calendar/task data reside exclusively on the user's local Windows workstation. Sophia never sells, leases, or transfers Google user data to third-party brokers, advertising networks, or external LLM training datasets.
  • •
    Google API Services User Data Policy: Sophia AI's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Everything Sophia Can Do on Your PC

Initiate WhatsApp voice and video calls, answer or end incoming calls, mute audio, search conversations, draft replies, and send messages completely hands-free.
